# proofread-body

`body_proofread.py` が gh issue/pr create の校正結果に添えて送る構造チェック。送るのは最初の `##` 見出しから下だけで、見出しより前のこの説明は送らない。

## 構造レビュー

この body は作成済み。下表から外れる項目を gh issue edit か gh pr edit で直す。外れる項目が無ければ何もしない。

| チェック     | 問い                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| 筆者の判断   | 筆者自身の結論が冒頭 1〜3 行にあるか。AI が書いた文がそのまま大半を占めていないか |
| 分量         | 半分の字数で同じことを伝えられないか                                              |
| 事実と意見   | 事実、推測、提案が分けて書かれているか                                            |
| 読み手の行動 | 求める行動が具体的か。「ご確認ください」でなく「X を判断する」の形か              |
| 読み手の負担 | 読み手が調べ直さずに判断できるか                                                  |
