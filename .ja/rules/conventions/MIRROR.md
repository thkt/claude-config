# Mirror Conventions

`.ja/` と英語側ファイルの対応に関する規約。

## 正と反映

`.ja/` を正とし、そこを起点に編集して同一コミットで英語側へ反映する。反映先は `.ja/` を除いたパス。

| 対象           | 規則                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 表現の向き     | 英語側の都合で生まれた表現を `.ja/` へ逆流させない。言語ごとの検査が要るならテストを分ける |
| テストの置き場 | 英語側だけ。`.ja/` のコードは実行されず、二重実行では古びるずれを検出できない              |
| 散文の言語     | `.ja/` で日本語、それ以外は英語。コメント、テスト名、アサーションメッセージが対象          |
| 例外           | 照合対象の実データは原語のまま。適用先はパスで決まる                                       |

## 反映の形

反映の形は内容で決める。翻訳対象のファイルは `cp` で同期しない。

| ファイル                                              | 反映                                                                                                                |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 散文を運ぶ (Markdown、プロンプトを内包するスクリプト) | 散文 (コメント/プロンプト/メッセージ文字列) を翻訳。コード構造、識別子、stopped 値、JSON キー、スキーマは同一に保つ |
| 散文を持たないスクリプト                              | 同一コピー                                                                                                          |
