# Markdown Conventions

`.claude/` 配下の Markdown ファイルに対する規約。コードブロック/インラインコードの内部は適用範囲外とする。

## ファイルスコープ

スコープは `.ja/` を除いたパスで判定する。

| スコープ     | パス                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| LLM-facing   | `CLAUDE.md`, `agents/**`, `skills/**`, `rules/**`, `.claude/workspace/**` |
| Human-facing | `docs/**`, `README.md`                                                    |

## 記号

`.ja` では textlint hook が `/` の前後を詰める。詰めた形が path に読める英字の列挙は読点にし、`CI/CD` や `try/catch` はそのまま、`/fix` のようなスラッシュコマンドは inline code で囲む。

| 記号 | 用途                            | 例                                  |
| ---- | ------------------------------- | ----------------------------------- |
| `/`  | AND 並列列挙                    | `Safety First/Output Verifiability` |
| `.`  | 独立したルールのセパレータ      | `Check scope. Do not skip`          |
| `()` | 補足条件のみ                    | `Skip for follow-up (same session)` |
| `>`  | 優先順位 (左を優先、不可なら右) | `CLI tool > built-in equivalent`    |
| `→`  | ステップ列挙                    | `Observe → analyze → conclude`      |
| `§`  | セクション参照                  | `phase.md § Gate ルール`            |
| `+`  | 構成要素の合成                  | `root causes + Gate decision`       |

## インラインコード

削除したときに誤読されるかどうかで判断する。`<branch>` のような angle-bracket は例外とする。

| 残す                                       | 削る                               |
| ------------------------------------------ | ---------------------------------- |
| 識別子やコマンドが通常テキストと混在する文 | 列名から型が自明な同型セルの列     |
| プレースホルダを含むトークン               | 強調目的のみの囲み                 |
| エスケープ/記号として識別が必要            | 記号で視覚的に区別されるリスト項目 |

## 禁止

| パターン                   | 適用範囲   | 修正                                                                               |
| -------------------------- | ---------- | ---------------------------------------------------------------------------------- |
| `≠`                        | All        | 肯定形に書き換えるか `is not X` を使う                                             |
| `()` で対比                | All        | `.` で文を分割する                                                                 |
| `—`                        | All        | `.` で文に分割するか、文脈に応じて `,`/`:`/`-` に置換                              |
| 行末 `:` や `Label: value` | All        | 見出しかテーブルに昇格、または散文化。リテラルのコロンは許可                       |
| 強調目的の全大文字         | All        | 通常の大小文字を使う                                                               |
| 段落内の物理改行           | All        | 1 段落 1 行で書く。ソフトラップはツールが処理                                      |
| テーブル後の段落           | All        | 説明 (ルール、コンテキスト、例外) はテーブル前に置く。表が導いた結論は表の下に残す |
| `**bold**`                 | LLM-facing | テーブルやセクションを使う。太字先頭の bullet はテーブルに変換                     |
| 文中の絵文字               | LLM-facing | 削除。ユーザーに見える絵文字は例外                                                 |
| Unicode 装飾               | Prose      | ASCII を使用する                                                                   |

## 参照

深度は Skills で 1 階層、Rules/Docs で 3 階層まで。

| 禁止パターン             | 理由                                           |
| ------------------------ | ---------------------------------------------- |
| 循環 (A → B → A)         | 解決不能な依存を生む                           |
| CLAUDE.md に既に含まれる | グローバルに読み込まれるファイルは再参照不要   |
| 予防的な参照             | 現コンテキストで読む必要があるものだけ参照する |

## セクション語彙

連番手順を持つ skill では、最上位の連番ユニットを `## Phase N` とする。

| 対象                 | 語彙                                          |
| -------------------- | --------------------------------------------- |
| 最上位の連番ユニット | `Phase N`                                     |
| Phase 内の第 2 階層  | `Step`。単一 Phase のテーブル内の番号列など   |
| 連番でない準備・参照 | 固有名 (Input、Setup、Output)。Phase ではない |
| 独立した列挙チェック | 観点やカテゴリの固有名。Phase ではない        |

## 重複指示の削除

| 重複相手                               | 削除の可否                                                   |
| -------------------------------------- | ------------------------------------------------------------ |
| システムプロンプト                     | 全ての行と節を覆うときだけ削除する。モデル更新時に再点検する |
| `output-styles/**`                     | `rules/` 側から削除しない。output style は切り替えられる     |
| 常時ロードされる他の `rules/` ファイル | 圧縮された言い換えの側を削り、判定基準を持つ表の側を残す     |
| 閾値やゲートを緩めることになるもの     | false positive の実例が出るまで削除しない                    |
| 逆引き索引として働く重複               | 残す。状況から原則を引く経路は索引にしかない                 |
