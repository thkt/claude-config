# plan の配分

`## Plan` を持つ入力を分けるとき、plan の各要素をスライスの Plan へどう渡すかを決める。`/think` を N 回走らせ直さないのが目的で、写せるものは写し、スライスごとに変わるものだけ書き直す。

## 先に、単位の切り方を見る

plan の unit がレイヤーごとに切られている場合、unit の部分集合はスライスにならない。1 スライスが複数 unit の一部ずつを要ることになり、配分では作れない。この形を見つけたら配分をやめ、垂直に切り直すため `/think` へ差し戻す。判定は unit の files を見て、schema、API、UI のどれか 1 層だけに寄っている unit が 2 つ以上あるかで決める。

## 要素ごとの渡し方

| 要素                | 渡し方                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| Outcome             | スライスごとに書き直す。そのスライス 1 本を終えた時点の完了状態を書く                                |
| root_cause          | epic のタイトルが `[Bug]` のときだけ、原因に触れるスライスへ写す                                     |
| test_command        | そのまま写す                                                                                        |
| base                | そのまま写す。epic ブランチへ集約するなら、その名前を全スライスで揃える                              |
| reference_module    | 同じモジュールを触るスライスへ写す。触らないスライスからは落とす                                    |
| Rules               | そのスライスの files に効く行だけ写す。効かない行を写すと、実装 agent が無関係な決まりごとを受け取る |
| Preconditions       | 現行コードに実在するものだけ写す                                                                    |
| U-NNN / T-NNN       | スライスごとに 001 から振り直す。id の一意性は 1 つの plan の中で足りる                              |
| Manual verification | そのスライスで確かめる項目だけ写す                                                                  |
| Backlog candidates  | epic に残し、スライスへは写さない                                                                   |

## 他スライスが作るものは前提でなく依存

Preconditions は build の Revalidate が着手前に現行コードベースへ再照合する。他のスライスがこれから作るファイルを写すと、そのスライスが終わるまで Revalidate が落ちる。落ちる理由は「まだ無い」で、plan の誤りとは見分けが付かない。

写す代わりに Blocked by へ書く。受け入れ基準に同じ形が出たときと同じ扱いで、順序の情報は依存として持たせる。

## 配分後の検算

各スライスの Plan は、それ単体で build が受け取れる形になっている必要がある。次の 3 点を数えて確かめる。

1. 全スライスの U-NNN を合わせると、元の plan の unit を過不足なく覆う。覆えていない unit は、被覆チェックの未カバーとして Phase 3 が提示する
2. 各 unit の files は 3 以下、tests は 4 以下。seam unit だけがこの上限の外にある
3. `seam: true` を持つ unit は 1 スライスにつき 1 つまで
