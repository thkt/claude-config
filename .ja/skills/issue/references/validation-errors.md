# 検証エラーの対処

${CLAUDE_SKILL_DIR}/scripts/validate-issue-body.py は `{errors, warnings, checks}` を JSON として標準出力へ書き出す。`errors` が 1 件以上ある場合は `exit 1` で終了する。下表に従って各エラーを修正し、このスクリプトを再実行する。

| エラー                                             | 対処                                                                                                                                         |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `missing_section:<name>`                           | 骨格から欠落した見出し、または骨格に無くても種別が必ず持つ見出しを戻す                                                                       |
| `type_mismatch:title=... template=...`             | タイトルの角括弧内にある種別を正とし、その種別に合うテンプレートを選び直して本文を書き直す。タイトルを書き換えて解消しない                   |
| `type_mismatch:title has no bracketed type prefix` | 種別判定で得た種別名の先頭を大文字にし、角括弧で囲んでタイトルの先頭に付ける                                                                 |
| `unknown_section:<name>`                           | 骨格にない見出しを削除するか、その内容を骨格にある見出しへ移す。このエラーは、リポジトリ内のテンプレートを骨格として使った場合には発生しない |
| `placeholder_left:<件数> [<最初の 1 件>]`          | エラーに示されたプレースホルダーを、求められている内容に置き換える                                                                           |
| `unfilled_section:<name>`                          | その節の内容を書く。内容のないチェックボックス、記号だけの箇条書き、`TBD` はいずれも未記入と判定される                                       |
