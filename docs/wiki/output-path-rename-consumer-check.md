# 出力パスの変更前に、予測可能な名前で読む consumer の有無を再確認する

## 内容

生成物やレポートの出力パス・命名を変更する前に、その予測可能な名前を頼りに読んでいる consumer が無いかを確認する。確認せずに変更すると、固定パスや命名規則に依存していた読み手が静かに参照を失う。

## 定型手順

1. 変更対象のパス・命名を頼りに読んでいる箇所を skills / rules / agents / docs 全体で検索する
2. 見つかった consumer があれば、変更と同時に追従させる
3. consumer がゼロであることを確認できたら、その旨を issue や PR に明記する

## 根拠

- #40 大型 docs 自動分割の feature 提案で「既存ファイルパスを変更する場合は、参照側への影響を事前検出する step を入れる」と制約に明記した
- #52 `audit-adr-gaps` の report slug 変更前に `docs/audit` を予測可能な名前で読む consumer の有無を再確認し、ゼロであることを確認済みだった
