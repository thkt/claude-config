# 同じ入力を両側でフィルタしてから件数だけを比較するテストは、実質的な差があっても一致してしまう。集合の内容で比較する

## 内容

二つの集合を比較するテストが、比較の前に同じ条件で両側をフィルタしていると、フィルタが両側を同時に動かすため、要素が抜け落ちても件数だけは揃って一致してしまう。差を検出するには、フィルタ後の件数ではなく集合の内容 (要素そのもの) を比較する。

## 定型手順

1. 二つの集合を比較するテストが、比較前に同じ条件で両側をフィルタしていないか確認する
2. フィルタが両側を同時に動かす形なら、件数比較を集合の内容 (要素そのもの) の比較に置き換える
3. 置き換え後、片側から要素を 1 つ落として本当に検出できるか確かめる
