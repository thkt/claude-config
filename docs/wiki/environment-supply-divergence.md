# ローカルと CI の差は環境が供給するものの違いから出る

## 内容

ローカルで通り CI で落ちる差は、コードでなく環境が供給するものの違いから出る。依存のインストール先、PATH に載る実行ファイル、終了コードの拾い方がその実体になる。差を見つけたら、どちらの環境が何を供給しているかを先に並べる。

## 定型手順

1. 落ちた側の環境が何を供給しているかを、実行ログから列挙する
2. 通る側の環境と突き合わせ、供給の差を特定する
3. 差が依存なら、CI がどこで install するかを確かめる
4. 差が終了コードなら、各コマンドの exit をどう集約しているかを確かめる
