# 不在を検査するテストは陽性対照 (検査を確実に落とす fixture) を常設しないと、対象が壊れても気づかず通過する

## 内容

不在・0 件を確認するテストは、検査そのものが壊れて何も検出しなくなっても green のまま通ってしまう。意図的に違反を注入した陽性対照を同じテストの中に常設し、その陽性対照から検査の手掛かり (識別子・パターン) を取り除いた写しに対しては検出漏れとして落ちることを確かめておく。パターンリストで判定する検査は、リストに無い形の違反も陽性対照でカバーできているか確かめる。

## 定型手順

1. 不在・0 件を検査するテストを書くとき、検査が確実に検出できるはずの違反を注入した陽性対照を用意する
2. 陽性対照から検査の手掛かりを取り除いた写しに対して同じ検査を走らせ、検出漏れとして落ちることを確認する
3. パターンリストで判定する検査は、リストに無い種類の違反も陽性対照として試す
