# 外部の挙動主張は commit sha やバージョンへ固定する

## 内容

外部リポジトリの状態やバイナリの挙動を根拠として引用するとき、その参照は commit sha やバージョン番号へ固定する。参照先は時間とともに動くので、固定しない主張は書いた時点でしか正しくない。

## 定型手順

1. 外部リポジトリの issue/PR やバイナリの挙動を根拠に使う前に、参照時点の commit sha かバージョン番号を確認する
2. 主張にその commit sha /バージョンを書き添える
3. 後で読み返す側が「今も正しいか」を確かめられるよう、固定した時点を明記する
