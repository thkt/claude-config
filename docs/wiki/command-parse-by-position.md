# コマンドの判定は語の有無でなく位置で行う

## 内容

hook がコマンドを判定するとき、コマンド文字列に語が含まれるかで決めない。`shlex` で分割し、その語が何番目に来るかを見る。語の有無だけで判定すると、引数や heredoc の中身に現れた語を誤って拾い、逆に第 1 位置以外へ置かれた本物を見逃す。

## 定型手順

1. `shlex.split` でコマンドを語へ分割する
2. 判定したい語が何番目に来るかを決める。パイプや `&&` で区切られた各断片の先頭を見る
3. heredoc の本体は判定の対象から外す
4. 位置の解析を通した結果でだけ許可と拒否を決める

## 参照コード

- `hooks/_lib/command_scan.py`（コマンドを断片へ分け、各断片の先頭語を返す）
- `hooks/security/git_sandbox_guard.py`（その解析結果で判定する側）
