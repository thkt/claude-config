# 0 件・不在の報告は陽性対照で確認してから出す

## 内容

grep や検索が 0 件、対象が「無い」と報告するとき、同じ探索手段が実在すると分かっているものには当たることを陽性対照で確かめてから真の不在と判定する。陽性対照を取らないと、探索手段自体が壊れている(誤ったパス接頭辞、フィルタの誤設定)場合も「無い」と誤って報告する。

## 定型手順

1. 0 件・不在という結論を書く前に、同じ探索手段で実在すると分かっているものを 1 つ検索する
2. そこで期待どおりヒットすれば、探索手段自体は機能していると確認できる
3. 陽性対照でもヒットしなければ、探索手段(パス、フィルタ、引数)を疑う
4. 陽性対照の結果を報告に添え、真の不在であることの根拠として残す
