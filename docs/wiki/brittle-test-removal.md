# 空振りするテストと対象の消えたテストは理由を残して消す

## 内容

実装を壊しても落ちないテストと、検査対象が退役したテストは、消す理由をコミットに残して消す。残すと本数だけが守りに見え、退行を通す。散文を grep で照合するだけのテストは、文言を書き換えると同時に期待値も書き換わるので、この形になりやすい。何を壊したときに落ちるはずかを言えないテストが対象になる。

判定は `rules/development/TESTING.md` の Whether the test swings at nothing が持つ。ここが持つのは、空振りと分かった後の扱い。

## 定型手順

1. 対象のテストが守っているものを 1 文で言う。言えなければ空振りを疑う
2. 実装側をその主張が壊れる形で壊し、テストが落ちるか確かめる
3. 落ちなければ、主張を捉える形へ書き直すか、消す
4. 消すときは、何を守っていたつもりで、なぜ守れていなかったかをコミット本文に書く
5. 検査対象が退役して消す場合は、退役した対象の名前を書く
